# Noutube based blockage of Youtube advertisements
This firefox extension blocks YouTube ads using client-side script injection and DOM manipulation. It is based on code from [Noutube](https://github.com/nonbili/NouTube).

## How to install

1. in Firefox, Right Click `yt-block.xpi`
2. Save it in your directory 
3. Click the menu button (three horizontal lines) and select **Add-ons and themes**.
4. Click the **gear icon** (settings cogwheel) near the top right of the Manage Your Extensions page.
5. Select **Install Add-on From File…** from the menu.
6. Find and choose your saved `yt-block.xpi` file, then click **Add**.
